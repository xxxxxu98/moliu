# r6 书审通读 agent 任务书模板（4 通道各一份，占位符在组装后替换）

## 待替换占位
- {BOOK_DIR} = temp/book-review/<slug>-0917
- {CH_RANGE} = 分配的章段（1-50 / 51-100 / 101-150 / 151-200）
- {FATE_LINES} = 从 book.json 命运台账提取的主角+重点角色命运线（由主会话生成）

## 任务书正文（发给 agent）

你是网文全书质量通读审查员。对《账房相公：我用穿透式审计清算朝堂》第 {CH_RANGE} 章逐章通读正文全文（目录 {BOOK_DIR} 下的 001.txt..NNN.txt，UTF-8），并对照 outlines.txt 中对应章的蓝图。

### 必带核对材料
1. 先读 {BOOK_DIR}/book.json 的伏笔台账与命运台账，提取分配章段内出场的全部角色的命运终态（死亡/下狱/去职/释放/越狱/复职），作为通读时的「命运线核对清单」：{FATE_LINES}
2. r5 轮 11 条 S1 的形态族是本轮重点猎物（同书系重犯概率高）：
   - A簇「押了又放」：角色被捕/被押后，后文无释放/押解/提审过程即自由出场（办公/领兵/日常）
   - A簇押地 teleport：同一在押角色跨章出现在相距千里的两个关押地
   - A簇在位皇帝被称「先帝/先皇」
   - B簇数字蒸发：前文确立的金额/数量/兵力在后文被无解释改写
   - C簇辈分断裂：同章内皇族辈分/排行矛盾
3. 口径类专项（r4 最大 S1/S2 来源）：官职/品级/袍服补子/年号/关押地/粮价银价等数字与称谓的全局一致性。特别核对：纪年是否混入真实年号（天启/弘治/嘉靖/成化/宣德/万历/洪武/天顺）或多套架空年号互斥。

### 审查维度（按 story-review rubric）
钩子链衔接 / 爽点兑现 / 人物一致性 / 跨章事实与命运状态 / 章界重演（上章结尾与下章开头是否复述重演）/ 设定复述 / 大纲禁区遵守 / 数字口径漂移 / 口径类专项（上述3）

### 输出格式（严格）
每条 Finding 一行：
`S<级> | ch<N> | <类别> | <一句话结论> | <原文引用≤60字> | <裁定：终稿实锤/过程告警已兜住/需再取样核实>`
- S1=连续性断裂/事实矛盾；S2=口径类不一致；S3=观感级（套路复读/AI腔）；S4=建议
- 区分三档裁定，不确定的标「需再取样核实」并说明取样方式
- 最后给一段段内总评：钩子链质量、AI腔词频观感、节奏

### 纪律
- 只读 {BOOK_DIR} 目录，不读其他目录
- 引用必须抄原文，不许转述
- 命运线核对清单中的角色，每个在段内出场都要核对其状态与台账是否一致
