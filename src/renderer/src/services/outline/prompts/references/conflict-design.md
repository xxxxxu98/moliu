# 冲突设计参考

## 冲突类型

### 1. 人与自我
**核心**：内心挣扎、自我怀疑、成长痛苦

**适用场景**：
- 主角面临道德抉择
- 内心成长时刻
- 性格转变节点

**经典模板**：
```
1. 触发事件：触发内心矛盾的事件
2. 内心挣扎：正反两面思想斗争
3. 关键抉择：做出选择
4. 代价与成长：付出代价，获得成长
```

### 2. 人与自然
**核心**：环境挑战、自然灾害、生存危机

**适用场景**：
- 荒野求生
- 末世灾难
- 恶劣环境

**经典模板**：
```
1. 环境威胁：恶劣环境出现
2. 生存挑战：面临生存压力
3. 克服困难：找到解决方案
4. 适应/改变：适应或改变环境
```

### 3. 人与人
**核心**：人际冲突、竞争对抗、恩怨情仇

**适用场景**：
- 与反派的对抗
- 与配角的冲突
- 误会与和解

**经典模板**：
```
1. 冲突起源：矛盾产生
2. 对抗升级：冲突加剧
3. 高潮对决：正面冲突
4. 结果与影响：冲突解决
```

### 4. 人与世界
**核心**：终极对抗、命运挑战、世界危机

**适用场景**：
- 终极Boss战
- 世界观危机
- 命运抗争

**经典模板**：
```
1. 危机揭示：危机出现
2. 准备与成长：积累力量
3. 终极对决：最终决战
4. 新秩序：改变世界
```

## 矛盾递进

### 四层递进结构
```
第一层：人与自我（内心挣扎）
    ↓ 主角需要先解决内心问题
第二层：人与自然（环境挑战）
    ↓ 环境压力促使主角成长
第三层：人与人的（人际冲突）
    ↓ 人际关系推动剧情
第四层：人与世界（终极对抗）
    ↓ 终极挑战
```

### 递进节奏
| 阶段 | 主要冲突 | 占比 |
|-----|---------|-----|
| 开篇 | 人与自我 | 20% |
| 早期 | 人与自然 | 25% |
| 中期 | 人与人的 | 35% |
| 后期 | 人与世界的 | 20% |

## 冲突设计原则

### 1. 冲突要有意义
- 推动剧情发展
- 促进角色成长
- 揭示主题

### 2. 冲突要有代价
- 失败要有后果
- 胜利要有代价
- 选择要有取舍

### 3. 冲突要真实
- 符合人物性格
- 符合世界观设定
- 符合逻辑

### 4. 冲突要有节奏
- 张弛有度
- 逐步升级
- 适时释放

## 反派设计

### 反派层级
| 层级 | 出现时间 | 功能 | 示例 |
|-----|---------|------|-----|
| 小反派 | 新手村 | 引导成长 | 纨绔子弟 |
| 中反派 | 中期 | 阻碍发展 | 宗门师兄 |
| 大反派 | 后期 | 终极挑战 | 幕后黑手 |

### 反派塑造
```
1. 可恨之处：让人讨厌的行为
2. 可悲之处：让人同情的背景
3. 可敬之处：让人尊敬的品质
4. 可畏之处：让人害怕的能力
```

### 反派与主角的镜像关系
- 相同起点，不同选择
- 相同目标，不同手段
- 相同困境，不同应对

## 经典冲突模板

### 扮猪吃虎
```
1. 隐藏实力：主角隐藏身份
2. 被轻视：被误解/被欺负
3. 危机时刻：紧要关头
4. 真实实力：展露实力
5. 震惊全场：打脸
```

### 绝地逆袭
```
1. 绝境：陷入困境
2. 挣扎：努力寻找出路
3. 转机：发现机会
4. 反击：反败为胜
5. 胜利：获得成功
```

### 以弱胜强
```
1. 实力差距：明显劣势
2. 分析对手：找出弱点
3. 智取：利用智慧
4. 险胜：艰难取胜
5. 收获：胜利果实
```

## 冲突强度控制

### S级：终极冲突
- 生死存亡
- 世界命运
- 不可调和

### A级：高强度冲突
- 重大利益
- 势力对决
- 激烈对抗

### B级：中等冲突
- 个人恩怨
- 竞争比赛
- 误会矛盾

### C级：低强度冲突
- 日常摩擦
- 小打小闹
- 轻微误会

### 冲突节奏
```
C → B → A → S → 解决 → 新冲突
```

## 情绪拉扯

### 斗地主法
```
1. 小角力：主角稍占上风（"稍占上风"很重要）
2. 反复拉扯：多次拉锯
3. 最终胜利：大获全胜
```

### 情绪曲线
```
高兴 → 紧张 → 松一口气 → 更大的危机 → 希望 → 绝望 → 转机 → 胜利
```

## 冲突检查清单

- [ ] 冲突有明确的目标
- [ ] 冲突有合理的起因
- [ ] 冲突有适当的发展
- [ ] 冲突有高潮的爆发
- [ ] 冲突有合理的结果
- [ ] 冲突有深远的影响
- [ ] 反派有足够的威胁
- [ ] 主角有成长的空间
