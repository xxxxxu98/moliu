# 爽点设计参考

## 爽点类型

### 1. 装逼打脸
**核心逻辑**：主角展示实力，打脸看不起他的人

**触发条件**：
- 对方先挑衅/轻视
- 主角隐藏实力或身份
- 关键时刻展示
- 对方震惊/后悔

**经典模板**：
```
1. 轻视场景：反派/路人看不起主角
2. 铺垫场景：暗示主角不简单
3. 展示场景：主角展现实力
4. 打脸场景：对方震惊/打脸
5. 收获场景：获得尊重/资源/妹子
```

### 2. 实力碾压
**核心逻辑**：以绝对实力压制对手

**适用场景**：
- 升级后的首战
- 复仇场景
- 势力展示

**关键要素**：
- 对手要有一定实力（否则没意义）
- 主角赢得漂亮
- 有观众见证

### 3. 意外收获
**核心逻辑**：意外获得宝物、能力或机缘

**收获类型**：
- 宝物/装备
- 能力/技能
- 功法/秘籍
- 人脉/资源
- 信息/情报

**关键要素**：
- 意外但不突兀
- 符合世界观
- 有代价或限制

### 4. 感情突破
**核心逻辑**：感情关系的重要进展

**阶段划分**：
| 阶段 | 描述 | 爽点 |
|-----|------|-----|
| 相遇 | 初次见面 | 心动 |
| 相知 | 了解深入 | 暧昧 |
| 相熟 | 关系升温 | 吃醋/误会 |
| 暧昧 | 临界状态 | 试探 |
| 表白 | 正式确认 | 甜蜜 |
| 相守 | 感情稳定 | 日常撒糖 |

### 5. 真相揭示
**核心逻辑**：揭开谜底或隐藏的真相

**适用场景**：
- 世界观揭示
- 人物身份揭秘
- 阴谋揭露
- 身世之谜

**关键要素**：
- 有足够铺垫
- 真相震撼
- 影响剧情走向

### 6. 复仇成功
**核心逻辑**：成功报复仇人

**复仇节奏**：
```
1. 铺垫：仇恨来源
2. 隐忍：积累实力
3. 反击：逐步碾压
4. 高潮：终极对决
5. 落幕：仇人下场
```

### 7. 英雄救美
**核心逻辑**：在危难中拯救异性

**关键要素**：
- 美人要有魅力
- 危机要够大
- 主角要帅/强
- 救得漂亮

### 8. 寻宝探险
**核心逻辑**：发现珍贵资源或秘境

**探险结构**：
```
1. 线索发现
2. 探索准备
3. 遭遇危险
4. 克服困难
5. 发现宝物
```

### 9. 境界突破
**核心逻辑**：实力或境界的提升

**突破类型**：
- 等级提升
- 领悟新技能
- 解锁新能力
- 获得传承

### 10. 智取胜利
**核心逻辑**：用智慧而非蛮力取胜

**适用场景**：
- 实力不如对手
- 身份限制
- 以弱胜强

## 爽点节奏

### 微爽点（每3000字）
- 小打脸
- 实力展示
- 信息获取
- 关系微进

### 小爽点（每9000字）
- 身份揭示
- 关系突破
- 资源获取
- 地位提升

### 大爽点（每21000字）
- 大战胜利
- 复仇成功
- 境界突破
- 真相揭示

## 爽点密度控制

### 问题诊断
| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 读不下去 | 爽点太少 | 增加微爽点 |
| 爽感不够 | 铺垫不足 | 延长铺垫 |
| 爽点疲劳 | 同类爽点太多 | 变换类型 |
| 节奏拖沓 | 爽点间隔太长 | 加快节奏 |

### 调整原则
1. **铺垫要充分**：大爽点前至少3章铺垫
2. **释放要干脆**：爽点场景不要拖沓
3. **节奏要递进**：后期爽点要比前期大
4. **类型要多样**：避免同类爽点连续出现
